# A2: Party engine (`apps/engine`)

Status as of Mon Nov 16 2026. This file is updated as the work lands; anything not listed under "Works" is not done.

## What works (and how it was verified)

- **Ledger** (`src/core/ledger.ts`): integer balances, per-market escrow, one signed `BalanceState` per affected member per atomic action, co-signature tracking. Invariant `sum(balances) + sum(escrows) == total deposits` is asserted after every commit. Verified by `src/core/ledger.test.ts` (8 tests).
- **Markets** (`src/core/party-core.ts`, `src/core/book.ts`): the shared lifecycle plus pool, AMM (LMSR) and bet modes, stake limits, positions, fills, disputes with atomic re-settlement, voids at cost, voice drafts, scorecard, rate limits. Verified by `src/core/party-core.test.ts` (32 tests, including 1000 random actions across all three modes with the invariant checked after each).
- **Full game with 5 bots, once per mode** (`src/full-game.test.ts`, 3 tests): in-process engine, all adapters mocked, mock replay at 20x. Asserts the invariant throughout, every market `final` or `voided`, every bot countersigned its final state, payouts sum to total deposits, scorecard has entries, announcer events and LED commands were emitted.
- **Server** (`src/server.ts`, `src/party.ts`, `src/engine.ts`): Fastify REST + `ws` hub implementing `protocol.ts`, question pipeline, lock triggers, resolution, end of game and settlement (request_close -> submit_state -> finalize -> withdraw), SQLite persistence (`src/store.ts`), static hosting (`src/static.ts`). Exercised end to end by the full-game tests; the per-endpoint tests are listed under "Left".
- **Bots** (`src/bots.ts`, `src/bots-cli.ts`): `pnpm --filter @huddle/engine bots -- --party CODE --n 5 [--url ...]`.

## What is mocked

Every adapter is a stub from `@huddle/shared/mocks` today (sports, question engine, ranker, Gemini, LLM, announcer, settlement). The engine imports only the factories, so real implementations drop in without engine changes. Nothing has been run against devnet, a real LLM, ElevenLabs, Gemini or QuickNode.

## Decisions (one line + reason)

| # | Decision | Why |
| --- | --- | --- |
| A2-1 | D6 (no bets while a state older than 10 s is un-countersigned) is enforced whenever `requireMemberSig` is true, in every settlement mode; `trusted` defaults `requireMemberSig` to false. | Points parties run the same vault rules through the mock, so they exercise co-signing; trusted-host is the documented escape hatch. |
| A2-2 | Stake cap: a player's total in one market <= `maxStakeFraction` x (available balance + what they already have in that market). | A stable reading of "50% of their balance" that does not shrink as they bet. |
| A2-3 | AMM exposure (for the cap and `locked`) is the cost basis of shares still held; a void refunds net cost (buys minus sells), clawing back profit already cashed out. | "Refunded at cost" has to undo every trade or money is not conserved. |
| A2-4 | One settlement path for resolve, void and changed results: compute the full distribution, apply only the difference to what was already paid. A member who cannot cover a claw-back is debited to zero; the house covers the rest, then credits are cut pro rata. | Atomic reversal, always conserves money, never a negative balance. |
| A2-5 | A host `resolve` or `confirm_result` on a resolved or disputed market is final (no second dispute window). | The host is the arbiter of disputes (PRD section 5). |
| A2-6 | One-tap Bet mode auto-matches only on binary markets and only offers within 10% of the model's fair odds; on categorical markets it posts an offer. | Protects one-tap users from bad prices; "anything but X" is not the same as backing one outcome. |
| A2-7 | A taker's position on a categorical bet market has outcome `not:<side>`. | `Position.outcome` has no way to say "against X". |
| A2-8 | AMM falls back to pool for a market when the house balance is below the per-market budget; the box gets an `error` message with code `insufficient_funds` explaining it. | The protocol has no notice message. |
| A2-9 | Drafts are sent to box connections only until they open. | PRD: a draft is "not yet visible". |
| A2-10 | At close, markets still disputed after 60 s are voided; markets with no result are voided at once. | Conservative: refund at cost when nobody decided. |
| A2-11 | If the settlement client does not know the party at close (in-memory mock after a restart), the engine settles locally with the shared `settleClaims` rules. Only for points / mock clients; a real vault failure leaves the party `closing` for a retry. | The mock vault forgets everything on restart. |
| A2-12 | `chain_event` is broadcast once per signature; a later sighting via QuickNode is re-broadcast once. | Lets screens show Streams as the source without triple events. |
| A2-13 | Keys live in `DATA_DIR/keys` (dir 700, files 600), never in SQLite; the host token is stored only as a SHA-256 hash. | Keeps secrets out of the database and the logs. |
| A2-14 | `timing.timeScale` divides every engine-controlled duration; tests run at 20x. | Lets a full game run in seconds with real timers. |
| A2-15 | Package entry is `src/lib.ts` (no side effects); `src/index.ts` is the process entrypoint only. | Importing `@huddle/engine` must not start a server. |
| A2-16 | The QuickNode webhook is refused when `QUICKNODE_STREAM_SECRET` is unset, and agent tools when `AGENT_TOOLS_SECRET` is unset. | Both can change state; never accept them unauthenticated. |
